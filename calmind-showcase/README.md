# Calmind Showcase Page

Mini landing page bilíngue para apresentar o projeto Calmind na comunidade de desenvolvedores da OpenAI.

## Como usar

1. Substitua `assets/screenshot.png` pela imagem real do seu projeto.
2. Abra `index.html` e troque os links `href="#"` pelos links reais:
   - Demo do projeto
   - Repositório no GitHub
   - Contato ou perfil
3. Suba a pasta para um repositório no GitHub.
4. Publique no Cloudflare Pages.

## Configuração no Cloudflare Pages

- Build command: deixe vazio
- Output directory: `/`
